# Career Compass AI – End-to-End Azure DevOps Project

## Project Overview

Career Compass AI is a cloud-native career guidance application deployed on Azure Kubernetes Service (AKS) using a complete Azure DevOps CI/CD pipeline. The project demonstrates modern DevOps practices including containerization, code quality analysis, image management, automated deployment, and Kubernetes orchestration.

---

## Architecture

GitHub Repository
↓
Azure DevOps CI/CD Pipeline
↓
SonarCloud Code Quality Analysis
↓
Docker Image Build
↓
Azure Container Registry (ACR)
↓
Azure Kubernetes Service (AKS)
↓
Application Access via Load Balancer
